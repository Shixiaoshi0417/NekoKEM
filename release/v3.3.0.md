# NekoKEM v3.3.0

## 简体中文

### 本版更新

v3.3.0 将 Android、Linux CLI、Windows CLI 和 Windows GUI 统一为同一应用版本，Core 保持 3.1。本版汇总 v3.2.0 之后的 Windows 支持、界面体验、性能与构建改进，并更新图标展示。

- **Windows 原生 CLI**：提供 Windows 10/11 x64 `nekokem.exe`，运行无需 MSYS2 或 OpenSSL DLL。命令参数与 Linux CLI 一致，双击或无参数运行直接进入生成密钥、加密、解密、公钥指纹、退出的五项菜单。
- **Windows GUI**：新增 Rust + Tauri 2 + Vue 3 + TypeScript 前端，通过窄接口调用共享 C17 Core；提供原生文件选择、粘贴 PEM 密钥、进度与取消，不在前端实现密码算法。使用时需要 Microsoft Edge WebView2 Runtime，并保留 EXE 旁的 `WebView2Loader.dll`。
- **五种语言**：Android、Windows GUI 与 CLI 支持简体中文、繁体中文、英语、日语、韩语，默认识别系统语言，不支持的语言回退英语。Windows CLI 保留 Linux 的 `--lang`、`--set-lang` 与持久化语言选择，读取 Windows 显示语言；GUI 共用其私有语言偏好。
- **GUI 交互**：加入页面过渡、按钮反馈与进度动画，遵循系统减少动态效果设置；改进高对比度、键盘导航、错误字段定位及原生文件对话框期间的操作状态。
- **流式性能**：减少 AES-GCM 流式处理中的缓冲区复制，保留 OpenSSL 汇编加速，配置 Argon2id 所需线程池。继续以 64 KiB 分块处理和检查取消；不降低私钥保护的内存、迭代次数或并行度，不承诺不同机器或系统有相同速度。
- **OpenSSL 4.0.3**：各平台固定集成官方版本并校验源码 SHA-256，构建检查实际链接版本和 Argon2 线程支持；保留静态链接、编译加固与文件安全检查。
- **两项工作流**：`CI` 统一构建和执行安全、语言、互操作、性能、Android API 26/35 与 Windows GUI 回归；`Release` 仅构建和打包 Linux、Android、Windows CLI/GUI，并保留依赖、二进制、签名及产物完整性检查。
- **图标与文档**：Android 保留现有方形白底图案；Windows CLI/GUI EXE 保留方形图案，将外部白色区域改为透明；README 使用独立圆角展示图。更新各平台 README、构建说明和发布说明。

### Android 升级

**v3.3.0 沿用 v3.2.0 的发布签名，可直接覆盖安装，无需再次卸载。** 升级前仍建议导出公钥和加密 NKPR 私钥，验证备份可读取，并保存私钥密码。

仅旧签名的 v3.1.x 用户需要先完成上述备份，再卸载旧版、安装新版并导入密钥。卸载会删除应用内部密钥与数据；没有可用私钥备份或忘记密码，将无法解密对应文件。指纹不能恢复密钥。历史签名更换记录保留在 [v3.2.0 发布说明](v3.2.0.md)。

### 格式、安全边界与限制

- **NKEM v3、NKPR v1 与 Core 3.1 保持不变**。仍使用 X448 + ML-KEM-1024、HKDF-SHA512 和 AES-256-GCM；header、AAD、KDF 输入与 domain、nonce/tag、指纹计算和 GCM 长度限制不变。NKEM v1/v2 不再支持。
- NKPR 私钥保护仍使用 Argon2id：64 MiB、3 次迭代、并行度 4；随机 salt、nonce、认证和敏感缓冲区清理保持原有要求。认证成功后才提交解密输出，取消或失败不提交未认证明文。
- Windows 仅支持本地固定 NTFS；检查所有者、ACL、可信父目录和硬链接数，拒绝网络/设备/管道、替代数据流及重解析点。Windows 断电持久性不能等同于已验证的 POSIX 目录 `fsync`，成对文件提交不具备跨文件崩溃原子性。
- **Windows CLI 与 GUI 均未进行 Authenticode 签名**，不使用 Android 签名材料。构建校验随包 Microsoft SDK loader 的签名和来源，但该校验不代表 Windows 应用已签名。
- GUI 仅加载本地内容，限制前端权限，并清除口令与私钥输入；JavaScript/IPC 可能产生临时字符串副本，不能保证 WebView 堆可靠清零。进程死亡、真实 SAF provider、并发文件修改与物理擦除仍有未验证边界。

本项目是实验性工具，**没有经过独立专业安全审计，不应视为生产级软件，不应用于保护重要或敏感数据**。

### 下载与校验

公开附件包括：

- `app-release.apk`：Android `arm64-v8a`，最低 Android 8.0 / API 26，目标 API 35。
- `NekoKEM-linux-x86_64.tar.gz`：Linux x86_64 静态 CLI。
- `NekoKEM-linux-aarch64.tar.gz`：Linux aarch64 静态 CLI。
- `NekoKEM-windows-x86_64.zip`：Windows 10/11 x64 原生 CLI。
- `NekoKEM-Windows-GUI.zip`：Windows 10/11 x64 GUI 和所需 SDK loader；系统需安装 WebView2 Runtime。
- `SHA256SUMS.txt`：上述五个构建包的 SHA-256。

下载后先使用 `SHA256SUMS.txt` 校验，再解压或安装。全部包来自本次修改后同一源代码版本的成功 Release 构建；发布时记录对应 CI/Release 链接、源码提交、Android 签名证书指纹和附件校验值。签名恢复包不作为公开 Release 附件。

## English

### What's new

v3.3.0 aligns Android, Linux CLI, Windows CLI and Windows GUI on one application version; Core remains 3.1. It brings together Windows support, interface, performance and build improvements since v3.2.0, and updates icon presentation.

- **Native Windows CLI**: Windows 10/11 x64 `nekokem.exe` runs without MSYS2 or OpenSSL DLLs. Its command arguments match the Linux CLI; double-clicking or running without arguments opens the five-option menu for key generation, encryption, decryption, public-key fingerprints and exit.
- **Windows GUI**: a Rust + Tauri 2 + Vue 3 + TypeScript frontend calls the shared C17 Core through a narrow interface. It offers native file dialogs, pasted PEM keys, progress and cancellation, without implementing cryptographic algorithms in the frontend. Microsoft Edge WebView2 Runtime is required; keep `WebView2Loader.dll` beside the EXE.
- **Five languages**: Android, Windows GUI and the CLI support Simplified Chinese, Traditional Chinese, English, Japanese and Korean. System-language detection is the default, with English fallback for unsupported languages. The Windows CLI preserves Linux's `--lang`, `--set-lang` and persistent language selection, using the Windows display language; the GUI shares its private preference.
- **GUI interactions**: page transitions, button feedback and animated progress follow the system's reduced-motion preference. High contrast, keyboard navigation, invalid-field focus and operation state during native file dialogs are improved.
- **Streaming performance**: reduce buffer copying in AES-GCM streaming, retain OpenSSL assembly acceleration, and configure the thread pool required for Argon2id. Processing and cancellation checks continue in 64 KiB chunks. Private-key protection memory, iteration count and parallelism are not reduced; speed is not guaranteed to be identical across machines or systems.
- **OpenSSL 4.0.3**: all platforms pin the official version and verify its source SHA-256. Builds check the actual linked version and Argon2 thread support, retaining static linking, compiler hardening and filesystem checks.
- **Two workflows**: `CI` builds and runs security, language, interoperability, performance, Android API 26/35 and Windows GUI regressions. `Release` only builds and packages Linux, Android and Windows CLI/GUI, while retaining dependency, binary, signature and artifact integrity checks.
- **Icons and documentation**: Android retains the existing square artwork with its white background. Windows CLI/GUI EXE icons retain the square artwork with the outer white area made transparent. README uses a separate rounded display image. Platform READMEs, build instructions and release notes are updated.

### Updating Android

**v3.3.0 retains the v3.2.0 release signer and supports an in-place update. No additional uninstall is required.** Before upgrading, backing up the public key and encrypted NKPR private key, verifying readable backups and retaining the private-key password is still recommended.

Only old-signer v3.1.x installations need those backups followed by uninstalling, installing the new app and importing the keys. Uninstalling deletes app-private keys and data. Without a usable private-key backup or its password, files encrypted for that key cannot be decrypted. A fingerprint cannot restore a key. The historical signing-key change remains documented in the [v3.2.0 notes](v3.2.0.md).

### Formats, security boundaries and limits

- **NKEM v3, NKPR v1 and Core 3.1 are unchanged**. X448 + ML-KEM-1024, HKDF-SHA512 and AES-256-GCM remain in use; headers, AAD, KDF inputs and domains, nonce/tag, fingerprint calculation and GCM length limits are preserved. NKEM v1/v2 are no longer supported.
- NKPR private-key protection still uses Argon2id with 64 MiB, 3 iterations and parallelism 4. Random salt, nonce, authentication and sensitive-buffer cleanup retain their requirements. Decrypted output is committed only after authentication; cancellation and failure do not commit unauthenticated plaintext.
- Windows supports local fixed NTFS only. It checks ownership, ACLs, trusted ancestors and hard-link count, rejecting network/device/pipe paths, alternate data streams and reparse points. Windows power-loss durability is not equivalent to verified POSIX directory `fsync`; paired-file commits are not crash atomic across files.
- **Neither Windows CLI nor GUI is Authenticode signed**, and neither uses Android signing material. Builds verify the bundled Microsoft SDK loader's signature and provenance; that does not sign the Windows applications.
- The GUI loads only local content, restricts frontend permissions and clears password/private-key inputs. JavaScript/IPC may create temporary string copies; reliable WebView heap zeroization is not guaranteed. Process death, real SAF providers, concurrent file edits and physical erasure retain unverified boundaries.

This is experimental software. **It has not undergone an independent professional security audit, must not be considered production-grade, and must not be used to protect important or sensitive data.**

### Downloads and verification

Public assets are:

- `app-release.apk`: Android `arm64-v8a`, minimum Android 8.0 / API 26, targeting API 35.
- `NekoKEM-linux-x86_64.tar.gz`: Linux x86_64 static CLI.
- `NekoKEM-linux-aarch64.tar.gz`: Linux aarch64 static CLI.
- `NekoKEM-windows-x86_64.zip`: native Windows 10/11 x64 CLI.
- `NekoKEM-Windows-GUI.zip`: Windows 10/11 x64 GUI and the required SDK loader; the system must have WebView2 Runtime installed.
- `SHA256SUMS.txt`: SHA-256 hashes of the five build packages above.

Verify downloads with `SHA256SUMS.txt` before extraction or installation. All packages come from the successful Release build of the same source revision containing these changes. Publication records include CI/Release links, the source commit, Android signer certificate fingerprint and asset hashes. The signing recovery envelope is not a public Release asset.
