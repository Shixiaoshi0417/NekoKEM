# NekoKEM v6.1.0

## 简体中文

### 本版更新

本版新增无签名的 iOS / iPadOS 应用，并为平板和 iPad 适配宽屏布局，MIUIX 风格加入液态玻璃效果，Material 3 Expressive 风格可选主题色。Android 与各平台 CLI/GUI 统一为 **6.1.0**，Core 仍为 **6.0**；NKEM、NKPR 文件格式和密码参数不变。

- **iOS 无签名 IPA**：新增 `NekoKEM-iOS-arm64-unsigned.ipa`，支持 iPhone 与 iPad（iOS 16 起）。与 macOS GUI 共用 SwiftUI 界面、Rust bridge 和 C17 Core，分文件、密钥、通讯录和设置四个标签页，页面使用系统分组列表，布局与 Android 一致；通讯录同样支持勾选加密、左右滑动置顶或删除、扫码核对指纹。文件经系统文件选择器选取，结果保存在 App 的「文稿」目录，新密钥写到「文稿/Keys」；私钥密码可保存到钥匙串。
- **平板与 iPad 布局**：Android 宽 600dp 起底部导航换成左侧导航，页面内容最宽 640dp 并居中；宽 840dp 起通讯录分两栏，左侧列表、右侧联系人详情。iPadOS 18 起标签页可展开为侧边栏，页面最宽 640pt 居中，宽窗口下通讯录同样分两栏。
- **MIUIX 液态玻璃（Android）**：滚动后收起的标题栏改为磨砂玻璃，平板上的左侧导航为悬浮玻璃侧栏，通讯录的添加按钮改为圆形玻璃按钮；系统支持跨窗口模糊时（Android 12 起），弹窗会模糊背后的页面。
- **Material 3 主题色（Android）**：设置「外观」新增「主题色」，可选蓝、紫、绿、青、橙、红，默认蓝色。Android 12 起「动态颜色」是主题色列表的第一项，也可用开关打开，默认关闭，开启后按壁纸取色。
- **界面细节**：Android、桌面和 iOS 的文件页只显示文件名或「尚未选择文件」，未选择文件时加密和解密按钮同为灰色；密钥页指纹写成「指纹：…」；置顶标记改为线条图钉图标；Android 设置页「主题」的值显示在右侧。
- **修复（iOS）**：进入生成密钥时保存位置回到「文稿/Keys」，不会覆盖刚导入或升级的密钥；密钥页的密码错误提示显示在密码弹窗中。

### 兼容性与升级

- Android **6.1.0 / versionCode 19**，最低 API 26、目标 API 36，仅 arm64-v8a。沿用 v3.2.0/v3.3.0 签名，可直接覆盖升级。
- 文件格式与 6.0.0 相同：6.1.0 与 6.0.0 互相打开对方的 NKEM 文件和 NKPR v3 私钥，公钥和指纹不变。
- 从 5.2.0 及更早版本升级时，6.0.0 的说明仍然适用：第一次解锁会把本机私钥改写为 NKPR v3，5.2.0 及更早版本打不开 NKPR v3 私钥，回退前请先用「导出给 5.2 及更早版本的私钥」（CLI 为 `export-legacy-private-key`）导出副本。详见 [v6.0.0](v6.0.0.md)。
- 未签名的 NKEM v3/v4 仍不认证发送者。NKEM 中的 AES-GCM 不提供密钥承诺性，NKEM v4/v5 由头部 HMAC-SHA512 承诺文件密钥。Argon2id 保持 64 MiB、3 次迭代、并行度 4。

### 平台与验证边界

- Windows 10/11 x64：CLI、GUI、MSI 和 EXE 安装程序均无 Authenticode 签名。保留本地固定 NTFS、私有 ACL 与路径检查。
- macOS Apple Silicon arm64：CLI 部署目标 11.0，原生 CI 基线 macOS 15；GUI 最低 macOS 13，使用 macOS 26 SDK 构建并在 macOS 26 上验证。不提供 Intel/Rosetta 构建。使用 ad-hoc 签名（GUI 启用 hardened runtime），没有 Developer ID 或 Apple 公证。
- iOS / iPadOS arm64：最低 iOS 16，使用 iOS 26 SDK 构建。IPA 未签名，没有描述文件和 entitlements，需要用 TrollStore、AltStore、SideStore 等自签工具安装，免费 Apple ID 重签的应用通常每 7 天需要续签；钥匙串能否使用取决于签名工具写入的 entitlements。CI 只在 iPhone 和 iPad 模拟器上自测加解密并截图，未在实机上验证。iOS 版不检查更新（设置页可打开 Release 页面），也没有「保存到指定文件夹」。
- Linux GUI：Ubuntu 24.04 构建，另在 Fedora 44 容器中安装并启动 RPM，在 Arch Linux 容器中构建并安装 Arch 包；需要 glibc 2.39+。Flatpak 版不检查更新。DEB/RPM 依赖 Noto Sans CJK 字体和 `curl`（检查更新），便携包和 AppImage 需要系统自行安装。RPM 无开发者 GPG 签名。Flatpak 与 AppImage 在 CI 中安装并启动；X11 启动检查不代表所有发行版或 Wayland 实机。Flathub 与 AUR 尚未上架。静态 CLI 继续提供。

本项目仍是实验性工具，未经过独立专业安全审计，不应视为生产级软件或用于保护重要、敏感数据。

## English

### What's new

This release adds an unsigned iOS / iPadOS app, wide layouts for tablets and iPads, liquid glass in the MIUIX style and a choice of theme colors in the Material 3 Expressive style. Android and every CLI/GUI application are **6.1.0**; Core stays **6.0**. The NKEM and NKPR formats and cryptographic parameters are unchanged.

- **Unsigned iOS IPA**: the new `NekoKEM-iOS-arm64-unsigned.ipa` runs on iPhone and iPad (iOS 16 or newer). It shares the SwiftUI interface, the Rust bridge and the C17 Core with the macOS GUI, with Files, Keys, Contacts and Settings tabs built from system grouped lists and laid out like the Android app; contacts likewise support selecting recipients for encryption, swiping to pin or delete, and verifying fingerprints by scanning a QR code. Files are chosen in the system document picker, results are saved to the app's Documents folder and new keys to Documents/Keys, and the private key password can be saved to the Keychain.
- **Tablet and iPad layouts**: on Android, from 600dp wide the bottom navigation becomes a side rail and page content is centred at up to 640dp; from 840dp contacts show two panes, the list on the left and the selected contact on the right. From iPadOS 18 the tabs can expand into a sidebar, pages are centred at up to 640pt, and contacts also show two panes in wide windows.
- **MIUIX liquid glass (Android)**: the collapsed title bar becomes frosted glass when the page scrolls, the tablet side rail is a floating glass bar, and the add button on Contacts is a round glass button; where the system supports cross-window blur (Android 12 and newer), dialogs blur the page behind them.
- **Material 3 theme colors (Android)**: Appearance settings gain **Theme color** with blue, purple, green, teal, orange and red, blue by default. From Android 12, **Dynamic color** is the first entry of that list and also has a switch; it is off by default and takes colors from the wallpaper when on.
- **Details**: the Files page on Android, desktop and iOS shows only the file name or "No file selected", and both Encrypt and Decrypt are grey until a file is chosen; the Keys page writes the fingerprint as "Fingerprint: …"; the pin mark is a line pin icon; on Android the Theme value sits on the right of its settings row.
- **Fixes (iOS)**: opening key generation resets the save location to Documents/Keys, so a new key no longer overwrites a key that was just imported or upgraded; a wrong password on the Keys page is reported in the password dialog.

### Compatibility and upgrading

- Android **6.1.0 / versionCode 19**, minimum API 26, target API 36, arm64-v8a only. The v3.2.0/v3.3.0 signer is retained for in-place updates.
- File formats match 6.0.0: 6.1.0 and 6.0.0 open each other's NKEM files and NKPR v3 private keys, and public keys and fingerprints stay the same.
- When upgrading from 5.2.0 or earlier, the 6.0.0 notes still apply: the first unlock rewrites your own private key as NKPR v3, NekoKEM 5.2.0 and earlier cannot open an NKPR v3 key, and before rolling back you should export a copy with "Export private key for 5.2 and earlier" (`export-legacy-private-key` in the CLI). See [v6.0.0](v6.0.0.md).
- Unsigned NKEM v3/v4 still does not authenticate senders. AES-GCM in NKEM provides no key commitment; NKEM v4/v5 commit to the file key with the header HMAC-SHA512. Argon2id remains 64 MiB, three iterations, parallelism four.

### Platform and validation boundaries

- Windows 10/11 x64: the CLI, the GUI, the MSI and the EXE installer are not Authenticode signed. Local fixed NTFS, private ACL and path checks remain.
- macOS Apple Silicon arm64: the CLI has deployment target 11.0 and a native CI baseline of macOS 15; the GUI needs macOS 13 or newer and is built with the macOS 26 SDK and tested on macOS 26. No Intel/Rosetta builds. Signatures are ad hoc (the GUI with the hardened runtime), without Developer ID or Apple notarization.
- iOS / iPadOS arm64: needs iOS 16 or newer and is built with the iOS 26 SDK. The IPA is unsigned, with no provisioning profile or entitlements, and is installed with a sideloading tool such as TrollStore, AltStore or SideStore; apps re-signed with a free Apple ID usually need renewing every 7 days, and whether the Keychain works depends on the entitlements the signing tool writes. CI runs the encrypt/decrypt self-test and takes screenshots on iPhone and iPad simulators only; the app has not been validated on physical devices. The iOS app does not check for updates (Settings opens the Release page) and has no decrypt-folder option.
- Linux GUI: built on Ubuntu 24.04, with the RPM also installed and started in Fedora 44 containers and the Arch package built and installed in Arch Linux containers; requires glibc 2.39+. The Flatpak build does not check for updates. The DEB/RPM depend on Noto Sans CJK fonts and `curl` (for the update check); with the folder archive or the AppImage, install them yourself. RPMs are not developer-GPG-signed. CI installs and starts the Flatpak and the AppImage; X11 launch tests do not establish every distribution or physical Wayland session. NekoKEM is not yet on Flathub or the AUR. Static CLI packages remain available.

This remains an experimental tool without an independent professional security audit; it is not production-grade software and should not protect important or sensitive data.
