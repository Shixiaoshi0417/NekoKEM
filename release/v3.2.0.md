# NekoKEM v3.2.0

## 简体中文

### 升级前必读：Android 签名密钥更换

本次正式 APK 使用新的发布签名，无法覆盖安装旧签名版本。**请先从旧版导出公钥与加密的 NKPR 私钥，确认两份备份可读取，并保存私钥密码，再卸载旧版、安装新版、导入密钥。卸载会删除应用内部的密钥与数据；没有可用私钥备份或忘记密码，将无法解密对应文件。仅保存指纹不能恢复密钥。** 签名密钥更换不会改变导出的 NekoKEM 密钥、指纹或文件协议。

### 新功能

- Android 与 Linux CLI 完整支持简体中文、繁体中文、英语、日语、韩语；默认跟随系统，不支持的语言回退英语。
- Android 设置提供语言选择与持久化，Android 13+ 同步系统级应用语言；支持长文本、深色模式与字体缩放。
- CLI 新增 `--lang` 和 `--set-lang`，可通过 `--set-lang system` 恢复跟随系统；优先级为命令行、用户配置、系统 Locale、英语回退。机器可解析输出和退出码保持兼容。
- README 与 SECURITY 提供完整中英双语及相对链接导航。

### 安全与正确性修复

- 严格检查 GCM 长度、ML-KEM ciphertext 长度、PEM 尾部及文件类型，拒绝会阻塞的 FIFO 输入和隐式私钥密码交互。
- 修复输出路径别名、Android SAF 写入前取消、失败恢复及备份流关闭问题；支持空明文，修复暂存 NKPR 导入识别。
- 强化 fuzz gate，crash、hang、异常退出、无效统计或超时均使 CI 失败；保留完整样本归档。

### 格式与平台

- 仅支持 **NKEM v3**：X448 + ML-KEM-1024、HKDF-SHA512、AES-256-GCM。NKEM v1/v2 已移除。
- **NKPR v1 是独立且有效的私钥容器**，仍使用 Argon2id + AES-256-GCM；其格式不变。
- 保留现有 v3/NKPR header、AAD、KDF 输入与历史 domain、nonce/tag、指纹和密码参数；Core 版本保持 3.1。
- Android：正式签名 APK，`arm64-v8a`，最低 Android 8.0 / API 26；Linux：x86_64 与 aarch64 静态 CLI。

### 验证与限制

发布前要求完整 Linux 密码学与文件安全回归、GCC static analyzer、UBSan、ASan/LSan、AFL++ smoke、Android JVM 回归，以及 API 26/35 真实模拟器 instrumentation 通过；两种 Linux 发行包分别在原生架构构建并运行回归。签名 APK 的构建与签名校验单独报告，不等同于设备测试。

本项目是实验性工具，**没有经过独立专业安全审计，不应视为生产级软件，不应用于保护重要或敏感数据**。真实 SAF provider、进程死亡恢复、并发文件修改、跨文件 rename 崩溃原子性及历史 v3 fixture 兼容性仍有未验证边界；闪存 overwrite 不保证物理擦除。

下载后使用 `SHA256SUMS.txt` 校验附件。构建来源、CI 链接、签名证书指纹与附件 SHA-256 将在实际发布日志中列出。

## English

### Read before upgrading: Android signing-key change

This official APK uses a new release signing key and cannot update an installation signed with the old key. **Before uninstalling the old app, export both the public key and encrypted NKPR private key, confirm that both backups are readable, and retain the private-key password. Then uninstall, install the new app, and import the keys. Uninstalling deletes app-private keys and data. Without a usable private-key backup or its password, files encrypted for that key cannot be decrypted. A fingerprint alone cannot restore a key.** The signing-key change does not change exported NekoKEM keys, fingerprints or file protocols.

### Features

- Complete Android and Linux CLI support for Simplified Chinese, Traditional Chinese, English, Japanese and Korean. The default follows the system; unsupported languages fall back to English.
- Persistent Android language selection, synchronized with system application languages on Android 13+; layouts accommodate longer text, dark mode and font scaling.
- CLI `--lang` and `--set-lang`; `--set-lang system` restores system detection. Priority: command line, user configuration, system Locale, English fallback. Machine-readable output and exit codes remain compatible.
- Complete Chinese/English README and SECURITY documents with relative language-navigation links.

### Security and correctness fixes

- Strict GCM length, ML-KEM ciphertext length, PEM trailing-data and file-type checks; reject blocking FIFO inputs and implicit private-key password interaction.
- Fix output-path aliases, Android SAF cancellation before writing, failure recovery and backup-stream ownership; support empty plaintext and correct staged NKPR import detection.
- Harden the fuzz gate: crashes, hangs, abnormal exits, invalid statistics and timeouts fail CI; preserve complete sample archives.

### Formats and platforms

- Only **NKEM v3** is supported: X448 + ML-KEM-1024, HKDF-SHA512 and AES-256-GCM. NKEM v1/v2 have been removed.
- **NKPR v1 remains a separate, valid private-key container**, using Argon2id + AES-256-GCM; its format is unchanged.
- Existing v3/NKPR headers, AAD, KDF inputs and historical domains, nonce/tag, fingerprints and cryptographic parameters are preserved. Core remains version 3.1.
- Android: official signed `arm64-v8a` APK, minimum Android 8.0 / API 26. Linux: static x86_64 and aarch64 CLI packages.

### Verification and limits

Publication requires the complete Linux cryptographic and filesystem regressions, GCC static analyzer, UBSan, ASan/LSan, AFL++ smoke, Android JVM regressions and actually executed API 26/35 emulator instrumentation to pass. Both Linux release packages are built and regression-tested on their native architectures. Signed APK build and signature verification are reported separately from device tests.

This is experimental software. **It has not undergone an independent professional security audit, must not be considered production-grade, and must not be used to protect important or sensitive data.** Real SAF providers, process-death recovery, concurrent file edits, crash atomicity across multiple renames and historical v3 fixture compatibility retain unverified boundaries. Flash overwrite does not guarantee physical erasure.

Verify downloaded assets with `SHA256SUMS.txt`. The published notes will include build provenance, CI links, signing-certificate fingerprints and asset SHA-256 hashes.
