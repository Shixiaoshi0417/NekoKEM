All desktop icons are conversions of Android `mipmap-xxxhdpi/ic_launcher.png`, without redrawing or replacing its artwork. `icon.png` is a byte-identical copy. Original SHA-256: `7274596c68e9fcaf906a37b63afec6b5b3416196b271cc59df3bf36810c32e17`. ICO includes 16, 32, 48, 64, 128 and 256 pixel sizes; the 256 pixel image is scaled from Android’s original 192 pixel image. CLI and Tauri GUI share these files.
