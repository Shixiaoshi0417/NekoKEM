All Windows CLI and Tauri GUI icons are conversions of the shared Android `mipmap-xxxhdpi/ic_launcher.png`. The original artwork is preserved; only the opaque black exterior corners were replaced with white. All PNG and ICO sizes have an opaque white background, including all four corners. `icon.png` and `desktop/public/icon.png` are byte-identical copies of the corrected Android 192-pixel PNG. Shared source SHA-256: `c4425f8ee453571228e8b0260667533ef1ec35e0ce812f61d3b1eb2caea09d76`. ICO includes 16, 32, 48, 64, 128 and 256 pixel sizes; the 256-pixel image is scaled from the shared 192-pixel master.
