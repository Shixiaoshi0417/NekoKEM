# Bundled fonts

Latin text only. Chinese, Japanese and Korean text falls back to the fonts of
the system: the ones Windows ships, and Noto Sans CJK on Linux, which the DEB
and RPM packages depend on.

| Files | Used for | Source | Licence |
|---|---|---|---|
| `MiSansLatin-*.ttf` | MIUIX style | https://hyperos.mi.com/font/ (MiSans Latin) | Xiaomi's MiSans terms: free for commercial use, may be embedded in software, and the software must state that it uses MiSans. The files are unmodified. |
| `GoogleSansFlex-*.ttf` | Material 3 Expressive style | Google Fonts, the 9pt static instances | SIL Open Font License 1.1, `GoogleSansFlex-OFL.txt` |
| `JetBrainsMono-*.ttf` | Fingerprints and key text | JetBrains Mono 2.304 | SIL Open Font License 1.1, `JetBrainsMono-OFL.txt` |

Settings names the fonts, as the MiSans terms ask.
